## Наблюдения и расхождения с каноном

- Точные дубликаты: REF-016 = REF-007, REF-049 = REF-048 (одинаковый SHA-256); REF-063 отличается от REF-062 только логотипом.
- Арены на референсах (двор древней секты, кладбище культиваторов, заражённое болото, руины секты, монастырь Иньян) **отсутствуют** в каноническом [stages.json](../.work/config/v7/stages.json) (`stage.jade_grove`, `stage.mist_cliffs`). Это гипотезы для GAME-ARCH-02, не новые ID.
- Главное меню (REF-047) показывает режимы «Испытания», «Бесконечный путь», «Событие» — сопоставить с [modes.json](../.work/config/v7/modes.json) (`mode.challenge_trials`, `mode.endless_limited`); «Событие» в каноне отсутствует.
- Экран выбора класса (REF-062) показывает «будущие специализации» и рейтинг сложности класса — в v7 нет контракта специализаций; кандидат для BUILD-SKILL/GAME-ARCH-03, не правило.
- Экран улучшения (REF-011) показывает редкость на карточках, Выбрать/Пропустить и реалм «Ци-Зарождение III» — согласуется с CHOICE-VIEWMODEL-001/DRAFT-CONTRACT-002 (Skip, редкость); отображение реалма требует ссылки на контракт Cultivation.
- Экраны экипировки/инвентаря (REF-019) и квестов (REF-053) не имеют контрактов в v7; не начинать без решения о scope.
- Листы есть для всех 4 классов и 3 из 13 обычных врагов (Мертвец Инь, Кровавый волк, Осквернённый культиватор); 10 врагов бестиария и 3 босса без визуальных референсов.
- Все изображения содержат запечённый RU/EN/CN текст; для runtime UI действуют ключи локализации и Godot Control (ADR-005, v5_assets 32G.3).

## Применение

- R0 — только look-dev, брифы генерации и сравнение стиля; сравнение в духе ref2game допустимо лишь как offline look-dev, не как runtime pipeline.
- R1 — нарезка в placeholder возможна только с P0-00 через asset manifest (asset_id, source sha256, processing version) и QA s17; оригиналы в `ref/` не изменяются.
- Никакой референс не становится игровым правилом: числа, режимы, специализации и арены требуют контракта и ADR/спеки.
- Новые файлы добавлять в catalog.json и перегенерировать README; валидатор сверяет SHA-256 и размеры.

# PLAYABILITY_GATES — короткие проверки «это игра, а не прототип»

- **Статус:** чеклист ревью (process guide). Не задаёт баланс, числа и правила; при конфликте действуют ADR, v7 и [GAME-UX-001](../spec/v7/game-ux-001-oct-2026.md).
- **Источник идей:** чеклисты studioigor/studioigor-skill `14d9d09` (MIT) — game-ness gates, juice, ship gates; переписаны под survivor-like на Godot. Не установлено: autopilot этого пакета обходит разрешения ([SKILLS_AUDIT](../development/SKILLS_AUDIT.md)).
- **Когда применять:** с P0-02 (первый играбельный цикл) при ревью каждого среза, затрагивающего игрока; до этого — только как требования к контрактам.

Каждый gate имеет способ проверки: **A** — автоматически (bot/replay/headless тест), **M** — метрика из прогона, **H** — ручной плейтест (результат записывается как наблюдение, не как доказанный факт).

## 1. Game-ness gates (12)

| # | Gate | Проверка | Контракт / система |
|---|---|---|---|
| G1 | Цель ясна в первые секунды забега без текста-туториала | H | Stage, UX |

| G3 | Угроза читается до урона: у каждой атаки есть telegraph, который нельзя скрыть настройками | A (danger-layer присутствует) + H | Enemy, Boss, [s14](../spec/core/s14.md), [s15](../spec/core/s15.md) |
| G4 | Каждое попадание, подбор и level-up дают отклик (визуал/звук) | A (событие → presentation cue) | Combat → PresentationBridge |

## 2. Juice — допустимые усилители отклика

Hit-flash и короткий knockback; числа урона с режимами off/aggregate/all; ограниченная тряска камеры с отключением; частицы и glow по отдельным ползункам; звуковые слои с приоритетом угроз. Правило: усилитель не меняет симуляцию (только View), всегда отключаем и не перекрывает danger-layer. Бюджет — [s24](../spec/core/s24.md).

## 3. Ship gates для любого играбельного билда

1. Билд запускается из чистого checkout по [DEV_ENVIRONMENT](DEV_ENVIRONMENT.md); headless smoke и тесты зелёные на Windows и Linux.
2. Golden replay воспроизводится побитно (seed, RunRulesSnapshot).
3. RU/EN: нет отсутствующих ключей в показанных экранах.
4. Сохранение переживает перезапуск; повторная выдача награды невозможна (run_uid, reward_event_id).
5. Известные ограничения записаны в evidence; FPS не обещаются без exported build на целевом железе.

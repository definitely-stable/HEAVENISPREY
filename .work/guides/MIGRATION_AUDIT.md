# Аудит переноса v6 → .work: что есть, чего не хватает

**Дата аудита:** 2026-11-11. Это аудит документации, **не** подтверждение игровой реализации.

## Перенесено в PR #1

- Исходный документ v6 — 2633 строки, сохранён целиком в [архиве](../archive/architecture-v6-original.md); SHA-256 источника фиксируется в [MANIFEST](../MANIFEST.json).
- 63 извлечённых тематических раздела, source anchors `s00`–`s31`, `v5_*`, `v6_*`; полные пути и статусы — в [MANIFEST](../MANIFEST.json).
- Исторический реестр 85 ссылок в [SOURCES](../research/SOURCES.md); **наличие URL не доказывает повторной актуальной проверки каждого источника**.
- Новая v7: поздние сложности, две расходуемые валюты, открытие и антифарм как дизайн-фикстуры, не Godot runtime.
- Гайд по выбору контекста **по предмету задачи**, без деления по AI-моделям.

## Что было упущено в первоначальном переносе

1. В прежнем источнике и его фрагментах остались устаревшие **таблицы закрепления задач за Codex/Claude/OpenCode**. Они отменены [ADR-004](../decisions/ADR-004-agent-context.md). Оригинал в архиве сохраняется, активный процесс — [WORKFLOW](WORKFLOW.md).
2. `s00` и `s06` имеют короткие технические имена, непригодные для быстрого поиска предмета; добавлен [семантический индекс](START_HERE.md) поверх стабильных ID.
3. Первоначальная проверка CI сопоставляла наличие файлов и строк в INDEX, **но не сверяла содержимое каждого раздела с исходной областью документа**. Требуется автоматическая сверка без сокращений для неизменённых фрагментов; адаптированные файлы должны быть помечены отдельно.
4. CI проверял ссылки только на главных страницах; исторические фрагменты тоже могут содержать ссылки на прежние файлы. Нужна двухуровневая проверка: строгая — для активных страниц, диагностическая — для исторических.
5. **v5 отдельные материалы:** семь технических `docs/*.md` дословно совпали с якорными секциями v6 и **дедуплицированы**. Оригинальный `claim_evidence.csv` перенесён в [research](../research/claim_evidence.csv). SHA-256 всех компонентов записаны в [source inventory](../archive/package-source-inventory.json). Сохранён один активный регламент, без распределения работы по AI-моделям.
6. **v6 Config Starter:** приведены к канонической схеме 2 классы, техники, статусы, карты, боссы, режимы, таланты, валюты, bot-сценарии, награды и RU/EN в [единый каталог v7](../config/v7/README.md). Неэквивалентные условия late game/режимов разобраны отдельно в [reconciliation](PACKAGE_RECONCILIATION.md), вместо механического копирования. Старые Python-скрипты schema 1 заменены [сквозным валидатором](../../scripts/validate_content.py).
7. Нет игрового runtime/теста Godot, RE-бинарников, обученных ботов, проверенного баланс-контента. Не заполнять этот пробел утверждениями о готовности.

## Проверка после исправлений

- **56 разделов** автоматически сопоставляются с оригинальным текстом после детерминированного преобразования относительных ссылок.
- **7 разделов** с прежними назначениями конкретных моделей адаптированы, отмечены в MANIFEST и снабжены ссылкой на оригинал.
- Актуальная документация проходит **строгую** проверку внутренних ссылок; для исторических разделов выдаются диагностические предупреждения.
- [Validator](../../scripts/validate_migration.py) запускается в Windows/Linux CI. Он не подменяет проверку неимпортированных пакетных артефактов.

## Приоритет исправлений

**P0:** убрать модельные назначения из действующих инструкций; статусы источников; восстановить проверку соответствия каждого перенесённого раздела.  
**P1:** дедупликация v5 и нормализация v6 завершены на уровне дизайн-контента; следующий шаг — Godot ContentRegistry, typed loading, импорт локализации и негативные тесты runtime.  
**P2:** генерация предметного индекса из metadata, проверка внешних URL по расписанию, доказательства связи ADR → тесты → PR.

## Остаточный риск и границы переноса

**Битовый архив двух ZIP не добавлен в Git**. Исходные SHA-256 и отображение каждого файла на новый контракт записаны в [inventory](../archive/package-source-inventory.json); отдельный отчёт v5 сохранён в предыдущих артефактах переписки. Содержательная интеграция ≠ битовое архивирование оригинальных пакетов. Runtime-сцены, боевой AI, реальные боты и баланс ещё не реализованы.

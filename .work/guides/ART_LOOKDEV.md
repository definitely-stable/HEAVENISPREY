# ART_LOOKDEV — сравнение с референсами и паспорт стиля (до production-ассетов)

- **Статус:** процесс для offline look-dev. Production-ассеты не создаются до утверждения art bible пользователем; генерация — только через уже утверждённую GPT imagegen capability ([AGENTS.md](../../AGENTS.md) п.3), конвейер — [s16](../spec/core/s16.md) (исторический контекст).
- **Референсы:** [ref/catalog.json](../../ref/catalog.json) и [ref/README.md](../../ref/README.md) (ART-REF-001). Все записи `production_ready: false`. Кандидаты R1 сейчас только UI-kit, иконки навыков и брендинг; персонажи, враги и окружение — R0 (только направление).
- **Источники идей:** studioigor/ref2game `da2978f` (MIT) — метрики сравнения и «style passport»; studioigor-skill `14d9d09` — art bible и карточка ассета. WebGL2 runtime ref2game **не используется**: рантайм только Godot 4.7.2 2D ([ADR-001](../decisions/ADR-001-stack.md)).

## 1. Паспорт стиля (заполняется в срезе ART-BIBLE-001, требует решения пользователя)

| Поле | Содержание | Откуда |
|---|---|---|
| Палитра | 8–12 опорных цветов + доли (золото / тёмный фон / акценты стихий) | измерить по R1 UI-kit |
| Тональность | распределение яркости: тени / средние / света | метрика `tones` |
| Контур и форма | толщина контура, силуэт при 1080p и 3440×1440 | [s14](../spec/core/s14.md) |
| Материалы | металл/нефрит/бумага талисманов, уровень детализации | R1 UI-kit, R0 персонажи |
| Свет | направление ключевого света; **glow, тени и текст не запекаются в спрайт** | правило ref2game, [s15](../spec/core/s15.md) |
| Читаемость | герой и telegraph врагов видимы поверх всех VFX | [PLAYABILITY_GATES](PLAYABILITY_GATES.md) G3, G10 |
| Запреты | чужие торговые марки, узнаваемые персонажи других игр, текст на изображениях | лицензия ассетов |

## 2. Метрики сравнения кандидата с референсом (offline, Pillow)

Детерминированные числа вместо «похоже / не похоже». Порог задаётся в паспорте стиля, не здесь.

| Метрика | Что сравнивает | Ловит |
|---|---|---|
| `palette` | расстояние между k-means палитрами (ΔE) | уход цвета |
| `tones` | гистограммы яркости по трём зонам | слишком светлый/плоский ассет |
| `lowfreq` | уменьшенные до 16×16 изображения | неверная композиция и масса |
| `side` / `grid` | профиль силуэта и заполнение сетки атласа | неверный размер, кадр, pivot |
| `diff` | попиксельная разница после нормализации | регресс при перегенерации |

Отчёт сохраняется рядом с кандидатом и ссылается на `REF-xxx` и sha256 из каталога. Инструмент (`scripts/art/compare_ref.py`) — отдельный срез ART-REF-002 после утверждения паспорта; сейчас метрики — контракт, не работающий код.

## 3. Карточка ассета

Каждый будущий ассет оформляется по шаблону [ASSET_CARD](../templates/ASSET_CARD.md): стабильный `asset_id`, связанные content ID, референсы, prompt hash, размеры, pivot, проверки и решение. Поля совпадают с manifest из [s16](../spec/core/s16.md), чтобы карточка становилась записью manifest без переписывания.

## 4. Порядок

ART-REF-001 (каталог, готово) → ART-BIBLE-001 (паспорт стиля, решение пользователя) → ART-REF-002 (инструмент метрик + тесты) → первые ассеты после P0-00 под [ADR](../decisions/README.md) и карточкой.

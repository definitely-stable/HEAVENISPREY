# Режимы и совместимость v7

Статус: принятый дизайн. Модификаторы и базовая сложность — независимые параметры, но **тоже имеют прогрессионные unlock gates**.

| Режим | Открытие | Награды |
|---|---|---|
| Normal | с начала | обычные |
| Hyper | победа на Standard | обычные с ограниченным бонусом |
| Hurry | завершены две разные карты | обычные с ограниченным бонусом |
| Endless (лимитированный) | победа на Hard | Печати только за первый полный цикл |
| Challenge Trials | победа на Небесной каре | награды по утверждённым испытаниям |
| Training | с начала | нет постоянного прогресса |
| Custom unranked | с начала | нет постоянного прогресса |

Порядок: проверить открытие → совместимость stage/difficulty/mode → собрать immutable RunRulesHash → начать забег. Числовой mode multiplier capped (проектная граница ×1.25); не умножать бесконечно бонусы пяти mutators. Телеграфы, VFX-настройки и язык не должны менять экономику.

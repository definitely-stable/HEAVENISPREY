# ADR-XXX — <решение>

- **Status:** PROPOSED / ACCEPTED / SUPERSEDED
- **Date:** YYYY-MM-DD
- **Context:** проблема и ограничения
- **Decision:** выбранное правило, независимое от модели AI
- **Alternatives rejected:** почему не выбраны
- **Consequences:** зависимости, производительность, UX, тесты
- **Supersedes / superseded by:** относительные ссылки
- **Verification:** команды и результаты либо NOT RUN
- **References:** первоисточники и даты

Не создавать ADR для каждой мелкой правки; использовать для принятых архитектурных изменений.

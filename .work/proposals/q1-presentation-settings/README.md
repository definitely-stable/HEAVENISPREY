# TASK_SPEC · Q1-PRESENTATION-SETTINGS

- **Status:** VERIFIED locally (2026-11-19); hosted CI on the PR
- **Goal:** a view-only settings store `PresentationSettings` reads and writes `user://settings.cfg` with the keys of `.work/config/v7/settings.example.cfg`, clamps values and falls back to defaults on a missing, corrupt or mistyped file. It is the base for the QUALITY-2026-11 wave 1 slices (screen shake, hit flash, damage numbers, own-skill opacity).
- **Non-goals:** no scene wiring, no pause or options UI (slice Q6), no audio keys (slice A1), no change to `game/core/` or to the simulation, replay or bot fixtures.
- **Inputs:** QUALITY-2026-11 §5 Q1 (`.work/roadmap/QUALITY_PLAN_2026-11.md`); [s15](../../spec/core/s15.md) setting names; [PLAYABILITY_GATES §2](../../guides/PLAYABILITY_GATES.md) (an amplifier never changes the simulation and can always be switched off).
- **Files allowed:** `scripts/validate_content.py`, `.work/config/v7/settings.example.cfg`, `tests/test_schema_coverage.py`, `tests/test_presentation_settings_parity.py`, `game/presentation/settings/presentation_settings.gd` (+ `.uid`), `game/tests/unit/test_presentation_settings.gd` (+ `.uid`), this file.
- **Dependencies:** Godot 4.7.2, GUT from the toolchain lock; `main` `c3d4a24`.
- **Contracts:** schema keys and defaults — `[localization] preferred_locale="auto"`; `[graphics] vfx_intensity=0.65, screenshake=0.40, hit_flash=1.0, own_skill_opacity=0.8, floating_damage_numbers="aggregate"` (`off|aggregate|all`); `[accessibility] font_scale=1.0`; `[playtest] log_choices=false` (new `bool` rule). Runtime clamps: unit values to 0..1, `own_skill_opacity` to 0.2..1, `font_scale` to 0.5..2. GDScript defaults equal the example file (Python parity test).
- **Acceptance:** validator rejects an unknown key, a bad enum, a non-boolean `log_choices` and a missing new key; GUT covers defaults, round trip, clamping, wrong types, a corrupt file, unknown keys and copying; the full GUT suite and Python tests pass on Windows and Linux CI.
- **Risks / rollback:** the store is unused until Q2; reverting removes it without side effects. Defaults are plan proposals (QUALITY-2026-11 §8 В1) and may change in later slices together with the example file.
- **Test commands:** `python scripts/validate_content.py` · `python scripts/validate_work.py` · `python -m unittest discover -s tests -v` · `python scripts/dev/godot_tool.py test`.
- **Evidence links:** local run of every workflow step (`python scripts/dev/local_ci.py`, base `c3d4a24`): 34 steps PASS including the full Python suite and `godot_tool.py test` (GUT 285/285, negative control fails as expected); gdlint was not installed locally and runs in hosted CI. Mutations caught: `MIN_OWN_SKILL_OPACITY = 0.0` fails the GUT clamp test, a disabled `bool` rule fails `test_schema_coverage`, a changed GDScript default fails the parity check.
- **Next action:** Q2 (screen shake), Q3 (hit flash), Q5 (own-skill opacity) on top of this store.

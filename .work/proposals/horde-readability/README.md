# TASK_SPEC · HORDE-READABILITY

- **Статус** — IN_PROGRESS.
- **Цель** — в плотной группе сохранить силуэт героя и направление атак, дать короткий локальный отклик на потерю HP.
- **База** — предупреждения богомола и фонаря из PR #101, `QUALITY-2026-11`, аудит GOLD-RUN-INTERFACE. Плейтест собирается поверх 15-минутного профиля и золотого интерфейса.
- **Границы** — порядок проходов отрисовки, раздельные заливка и контур предупреждения, эффект попадания по герою, кадры и регрессия. Слой симуляции, числа атак, раскладка HUD и настройки из Q1 живут в своих срезах.
- **Разрешённые файлы** — `RunView`, `RunEffectsPasses`, `AttackTelegraph`, проверка сцены, этот контракт и запись в CURRENT_STATE.
- **Приёмка** — герой сохраняет тон одежды в момент попадания и под вспышкой своей техники. Обводка и направление угрозы видны внутри плотной группы в тени и у жаровни. На кадрах в цвете и в сером различимы широкая дорожка рывка и ось выстрела. Изменение порядка слоёв оставляет журнал и digest мира совпадающими на одинаковом журнале. Повторный урон внутри существующего интервала 0,45 с не запускает сигнал заново. Замер 1080p при 80 и 300 врагах показывает p95 и максимальное количество вызовов. Результат сверяется с бюджетом ADR‑014.
- **Проверки** — `python scripts/validate_work.py`, `python scripts/validate_encounter_proposal.py`, `python -m unittest discover -s tests -v`, Godot GUT, два нативных replay.
- **Откат** — отдельная ветка поверх PR #101. Порядок слоёв и отклик устраняются одним откатом.

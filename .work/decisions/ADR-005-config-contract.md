# ADR-005 — контракты контента и локализации
**ACCEPTED DESIGN**, не реализован. Все определения версионированы, имеют стабильные IDs и строки через i18n keys, а не встроенный текст. Конфигурация difficulty+stage+modes формирует immutable RunRulesHash; награды идемпотентно начисляются по run_uid/reward_event_id.

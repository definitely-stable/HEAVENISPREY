# ADR-004 — модельно-независимый процесс и проектная память

**Статус:** ACCEPTED (исправлено 2026-11-11). Приоритет над историческими таблицами распределения задач.

Долгосрочные правила хранятся в коротком [AGENTS.md](../../AGENTS.md). [Предметный индекс](../guides/START_HERE.md) и [карта задач](../indexes/AGENT_ROUTING.md) определяют **документы, необходимые для изменения**, а не исполнителя или модель.

Требования к качеству одинаковы для человека и любого AI-инструмента: task contract → изменения → воспроизводимые тесты → evidence → PR/review. Нельзя фиксировать за Codex/Claude/Opus/OpenCode эксклюзивную ответственность за подсистемы, файлы, ревью или архитектуру.

Возможности конкретных инструментов, например встроенная GPT imagegen для ассетов, относятся к **каталогу инструментов**, а не к назначению ролей.

Исторические советы по разделению труда остались в [архиве v6](../archive/architecture-v6-original.md) для проверки происхождения, но не являются действующими инструкциями. Документы адаптации помечаются в манифесте; [правила документации](../guides/DOC_STANDARDS.md).

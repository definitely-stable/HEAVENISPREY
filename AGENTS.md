# HEAVENISPREY — правила работы в репозитории

Эти правила **общие для любого AI-агента и человека**. Не назначать подсистемы конкретным моделям или сервисам.

1. Прочитать [предметную карту](.work/guides/START_HERE.md), затем только релевантные документы по [карте задач](.work/indexes/AGENT_ROUTING.md). Не загружать архив v6 целиком без необходимости.
2. При конфликте действуют [ADR](.work/decisions/README.md) и актуальные [v7 спецификации](.work/spec/v7/late-game-progression.md); прежние варианты — контекст, не повод отменить новые решения.
3. Основа: **Godot 4.7.2 2D + typed GDScript**. Нативный код только после подтверждённого профилированием CPU-hotspot. Создание визуальных ассетов — через уже утверждённую GPT imagegen capability, без новых обязательных платных API.
4. Содержимое должно иметь стабильные ID, версии схем, ключи RU/EN, детерминированные seed, проверяемые правила наград по run_uid и reward_event_id.
5. Для любой задачи записать цель, границы изменения, зависимости, тесты и evidence по [TASK_SPEC](.work/templates/TASK_SPEC.md). Не менять чужие несвязанные файлы; отдельная ветка и PR. **Обычные архитектурные/документные изменения:** после успешного CI и проверки diff закрывать задачу merge в `main` в рамках согласованного запроса, не накапливать открытые PR и не требовать повторного разрешения. **Исключения:** явный запрет пользователя, смена согласованного scope, разрушающие изменения, изменения нормативных продуктовых решений без согласования или неустранённые блокеры — не мержить. Merge документа-предложения не означает утверждение его дизайна.
6. На **текущем** этапе выполнять `python scripts/validate_work.py` и `python -m unittest discover -s tests -v`; после появления игры дополнительно Godot headless/game tests.
7. Не считать подготовленные спецификации/JSON работающей игрой. Сообщать реальные HEAD, PR, CI, acceptance, blockers, next action, дату проверки, а не предположения.
8. Описания ролей конкретных моделей в [оригинальном архиве v6](.work/archive/architecture-v6-original.md) являются **устаревшими историческими предложениями** и не применяются.
